- [x] [SPEC-2] Ajouter à `httpError` le paramètre `model` et lever, quand `res.status === 404` et `geminiErrorOf(text)?.status === "NOT_FOUND"`, `new LLMError("MODEL_NOT_FOUND", "Gemini has no model '<model>' (404 NOT_FOUND from <url>): <extrait>")`, tout autre 404 restant `API_ERROR` ; H7 nommée dans l'en-tête du module avec son test verrou — fichier attendu : src/llm/providers/gemini/gemini-llm-provider.ts
- [x] [SPEC-3] Entourer l'appel à `fetchFn` d'un `try` dans `complete()` et, sur rejet `cause`, lever `new LLMError("API_ERROR", "Gemini request to <url> failed: <excerpt(String(cause))>")` sans option `cause` — fichier attendu : src/llm/providers/gemini/gemini-llm-provider.ts
- [ ] [SPEC-4] Remplacer `res.json()` sur le chemin `ok` par `readBody(res)` puis `JSON.parse(text)` dans un `try`, et lever `API_ERROR` « Gemini <res.status> response is not JSON: <excerpt(text)> » si l'analyse échoue, « Gemini <res.status> response is not a JSON object: <excerpt(text)> » si la valeur est `null`, n'est pas de type `object` ou est un tableau, avant d'appeler `fromGeminiResponse` — fichier attendu : src/llm/providers/gemini/gemini-llm-provider.ts
